Déposer ici l’image officielle originale, sans la modifier :
animora_logo.png

Le dossier assets/images/ est déclaré dans pubspec.yaml. Flutter intégrera
automatiquement le PNG lorsqu’il sera présent. Faire ensuite un redémarrage complet
de l’application (pas uniquement un hot reload).

Aucune image de substitution n’est fournie. Tant que le fichier est absent,
l’interface affiche le message « Logo officiel à ajouter ».
